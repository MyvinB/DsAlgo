# Project Context for Kiro

This is a DSA practice repo. There is a spaced repetition system in `blind75_tracker.json`.

When the user asks about today's problems, assignment, leetcode, or review:
1. Read `blind75_tracker.json` AND `extra_tracker.json`
2. Calculate current day from `meta.start_date` vs today
3. Show:
   a. **New problems**: where `day` == current_day (from blind75 tracker)
   b. **Active recall / Reviews**: ALL problems where `next_review` <= today's date from BOTH trackers. These are critical — spaced repetition only works if reviews are surfaced consistently.
4. Always show reviews even if there are no new problems. Active recall is the priority.
5. After user reports completion ("done LC X, rating Y"), update the correct file
6. For problems not in blind75_tracker, use LeetCode GraphQL to get topic/difficulty and add to extra_tracker.json
   - curl -s -X POST https://leetcode.com/graphql -H "Content-Type: application/json" -d '{"query":"query{question(titleSlug:\"SLUG\"){questionId title difficulty topicTags{name}}}"}'
